# Code of conduct

dictAItor follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the code and not the person,
and make room for newcomers. Harassment, insults and personal attacks are not welcome in
issues, pull requests or any other project space.

## Reporting

If someone's behaviour bothers you, contact the maintainer privately through GitHub
(the [@ProductPope](https://github.com/ProductPope) profile) instead of replying in public.
Reports are handled confidentially. The maintainer may edit or remove comments, and
warn or block people who break these rules.
